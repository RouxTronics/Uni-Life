# Questions 

## Q.1 -  What is the main purpose of exception handling in Java?

To detect and manage runtime errors to maintain the normal flow of the application.

## Q.2 - Unchecked exceptions are checked at compile-time in Java.

  False

## Q.3 -  Which of the following is an example of an unchecked exception?

NullPointerException

## Q.4 - What is the result of trying to divide a number by zero in Java?

It throws an ArithmeticException.

## Q.5 - What keyword is used to define a block of code that may throw an exception?

Try

## Q.6 - All exceptions in Java are subclasses of the class Throwable. 

True
