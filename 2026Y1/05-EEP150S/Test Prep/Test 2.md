# True/False
## Chapter 9 

| Nr  | Question                                                                                                                                                      | Answer | Concept                       | Reason                                                                                                                                               |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ | ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | When using the superposition theorem, each ideal voltage and current source must be replaced by an open circuit.                                              | False  | Superposition: Source Removal | Voltage sources are replaced by short circuits; only current sources are replaced by open circuits.                                                  |
| 2   | Theveninʹs theorem permits the reduction of any two -terminal linear dc network to one having a single voltage source and a series resistor.                  | True   | Thevenin Theorem              | **Thevenin’s Theorem** reduces a network to a single **voltage** source and a **series** resistance.                                                 |
| 3   | Nortonʹs theorem permits the reduction of any two-terminal linear dc network to one having a single current source and a series resistance.                   | False  | Norton Theorem                | **Norton’s Theorem** reduces a network to a single **current** source and a **parallel** resistance.                                                 |
| 4   | Under maximum power transfer conditions, the operating efficiency of a system is 100%.                                                                        | False  | Max Power Efficiency          | Maximum power occurs when $R_L = R_{Th}$. At this point, half the power is lost to internal resistance, meaning **efficiency ($\eta$) is only 50%**. |
| 5   | The reciprocity theorem is applicable only to single-source networks.                                                                                         | True   | Reciprocity Theorem           | It applies to linear, bilateral, single-source networks where the ratio of excitation to response remains constant if their positions are swapped.   |
| 6   | The resistance calculated using Nortonʹs theorem is equal to the resistance calculated using Theveninʹs theorem for the same electrical network.              | True   | $R_N$ vs. $R_{Th}$            | Since both represent the equivalent resistance looking back into the same network with sources disabled, **$R_{Th} = R_N$**.                         |
| 7   | The total power delivered to a resistive element can be determined by the sum of the power levels established by each source.                                 | False  | Power Superposition           | Because $P = I^2R$ or $P = \frac{V^2}{R}$, power is a **quadratic (non-linear)** function. You cannot simply sum individual power values.            |
| 8   | While using superposition theorem, a voltage source is replaced by an open circuit.                                                                           | False  | Superposition: Voltage        | Replacing a voltage source with an open circuit would result in an undefined voltage; it must be **shorted** to ensure $V = 0$.                      |
| 9   | While using superposition theorem, a current source is replaced by a short circuit.                                                                           | False  | Superposition: Current        | Replacing a current source with a short would still allow current to flow; it must be **opened** to ensure $I = 0$.                                  |
| 10  | For any physical network, the value of $E_{Th}$ can be determined experimentally by measuring the open-circuit voltage across the load terminals.             | True   | $E_{Th}$ Measurement          | $E_{Th}$ is defined as the voltage across the terminals when no load is connected ($V_{oc}$).                                                        |
| 11  | The primary difference between the equivalent circuit of Norton and Thevenin is that Norton's circuit consists of voltage and a series resistor.              | False  | Norton Circuit Build          | The "primary difference" is that Norton uses a **current source in parallel** with a resistor, not a voltage source in series.                       |
| 12  | The superposition principle is applicable to power effects because the power loss in a resistor varies as a function of the square of the current through it. | False  | Power & Linearity             | Superposition only works for **linear** relationships ($V=IR$). The square of the current/voltage makes power calculation non-linear.                |
| 13  | The Norton and Thevenin equivalent circuits can be found from each other by using source transformation.                                                      | True   | Source Transformation         | You can convert between them using $E_{Th} = I_N \times R_{Th}$. This is a key tool for nodal and mesh analysis.                                     |
| 14  | The efficiency of a system is defined by the ratio of the power delivered to the load to all the power supplied by the source.                                | True   | System Efficiency             | Efficiency is formally defined as $\eta = \frac{P_{out}}{P_{in}} = \frac{P_{load}}{P_{source}}$.                                                     |

| 1      | The peak value of a waveform is the maximum instantaneous value measured from the zero-volt level. | **True**   | Peak Amplitude ($V_m$)      | The peak value ($V_m$ or $I_m$) is the highest point reached relative to the horizontal axis.                                  |
| 2      | The quantity $\pi$ is the ratio of the circumference of a circle to its diameter.                  | **True**   | Mathematical Constants      | By definition, $\pi = C/d$. In AC, this relates the linear frequency to angular frequency ($\omega = 2\pi f$).                 |
| 3      | The cosine curve leads the sine curve by $180^\circ$.                                              | **False**  | Phase Relationship          | A cosine curve leads a sine curve by exactly **$90^\circ$** ($\cos \theta = \sin(\theta + 90^\circ)$).                         |
| 4      | The average value of a sine wave is zero.                                                          | **True**   | Average Value ($V_{avg}$)   | Over a **full cycle**, the positive and negative areas are equal and cancel out. (Note: For a _half-cycle_, it is $0.637V_m$). |
| 5      | The duration of an alternating cycle is called a period.                                           | **True**   | Period ($T$)                | The period is the time (in seconds) required for a waveform to complete one full cycle.                                        |
| 6      | There are $57.3^\circ$ in one radian.                                                              | **True**   | Radian Measure              | One radian is $180^\circ/\pi$, which is approximately $57.295^\circ$.                                                          |
| 7      | The SI unit of frequency is called a hertz.                                                        | **True**   | Frequency ($f$)             | Named after Heinrich Hertz, $1\text{ Hz}$ equals one cycle per second.                                                         |
| 8      | The SI unit of radian frequency is radians per second.                                             | **True**   | Angular Velocity ($\omega$) | Radian frequency $\omega$ is measured in $\text{rad/s}$ and calculated as $2\pi f$.                                            |
| 9      | $R$, $L$ and $C$ elements have response characteristics that affect all alternating waveforms.     | **True**   | Passive Components          | $L$ and $C$ introduce reactance ($X_L, X_C$), which varies with frequency, unlike pure $R$.                                    |
| 10     | Increasing the frequency of a waveform increases the period.                                       | **False**  | Frequency/Period            | Frequency and Period are inversely proportional ($T = 1/f$). Higher frequency means a **shorter** period.                      |
| 11     | If a waveform crosses the axis with a positive slope $90^\circ$ sooner, it is said to lag.         | **False**  | Phase Lead/Lag              | If it crosses "sooner" or "to the left" of another, it is said to **lead**, not lag.                                           |
| 12     | The effective value of any current or voltage is the value indicated on a dc meter.                | **False**  | RMS vs. DC                  | A standard DC meter reads the average value ($0\text{V}$ for AC). An **RMS meter** is needed to read the effective value.      |
| 13     | The equivalent dc value of a sinusoidal current or voltage is $70.7\%$ of its peak value.          | **True**   | Effective (RMS) Value       | For a sine wave, $V_{rms} = \frac{V_m}{\sqrt{2}} \approx 0.707 \times V_m$.                                                    |
| 14     | A true RMS meter will read the effective value of any waveform.                                    | **True**   | RMS Measurement             | Unlike "average-responding" meters, true RMS meters calculate the heating effect of any wave shape (square, saw, etc.).        |
## Chapter 14

| **Nr** | **Question**                                                                | **Answer** | **Reason**                                                                                                                                                                        |
| ------ | --------------------------------------------------------------------------- | ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1**  | The derivative of a sine wave is maximum at the peak amplitude.             | **False**  | The derivative (rate of change) is **zero** at the peak because the slope of the tangent line is horizontal. The maximum rate of change occurs as the wave crosses the zero-axis. |
| **2**  | The voltage across an inductor leads the current through it by $90^\circ$.  | **True**   | In a purely inductive circuit, the voltage $v_L$ reaches its maximum value $90^\circ$ before the current $i_L$.                                                                   |
| **3**  | Inductive reactance increases directly in proportion to frequency.          | **True**   | Inductive reactance is defined by $X_L = 2\pi fL$. Because $f$ is in the numerator, $X_L$ increases linearly as frequency increases.                                              |
| **4**  | The more reactive the load, the lower the power factor.                     | **True**   | A higher reactive component increases the phase angle ($\theta$) between voltage and current. Since $F_p = \cos\theta$, a larger angle results in a smaller (lower) power factor. |
| **5**  | The complex conjugate is found by changing the sign of the real part.       | **False**  | The complex conjugate is found by changing the sign of the **imaginary** part ($j$ component) in rectangular form, or the sign of the angle in polar form.                        |
| **6**  | The length of a phasor is called the modulus or magnitude.                  | **True**   | In phasor notation, the length represents the RMS or peak magnitude of the sinusoidal quantity.                                                                                   |
| **7**  | Phasor algebra is applicable only for waveforms with different frequencies. | **False**  | Phasor algebra can only be used to add or subtract waveforms that have the **same frequency**.                                                                                    |
| **8**  | The derivative of a sine wave is a cosine wave.                             | **True**   | Mathematically, $\frac{d}{d\theta}(\sin \theta) = \cos \theta$. In circuits, this explains why inductor voltage (the derivative of current) is shifted by $90^\circ$.             |
| **9**  | For a purely resistive element, voltage and current are in phase.           | **True**   | In a resistor, there is no phase shift; the voltage and current waveforms cross the zero-axis and reach their peaks at the same time.                                             |
| **10** | For an inductor, the voltage lags the current through it by $90^\circ$.     | **False**  | This is the opposite of the actual relationship; voltage **leads** the current ($ELI$ mnemonic).                                                                                  |
| **11** | Inductive reactance does not dissipate electrical energy.                   | **True**   | An ideal inductor stores energy in its magnetic field and returns it to the circuit; it does not dissipate energy as heat like a resistor.                                        |
| **12** | Unlike inductive reactance, capacitive reactance dissipates heat.           | **False**  | Like inductors, ideal capacitors are reactive elements that store energy (in an electric field) rather than dissipating it.                                                       |
| **13** | A power factor of 1 indicates that maximum power is being delivered.        | **True**   | A power factor of 1 ($100\%$) means the load is purely resistive, and all delivered power is "real" or average power ($P = EI$).                                                  |
| **14** | Leading or lagging is not a consideration with power factor.                | **False**  | The power factor must be identified as **leading** (capacitive) or **lagging** (inductive) to fully describe the circuit's behavior.                                              |
