## 4 Phases 

- **Fetch**: the CPU fetches an instruction from memory, storing that instruction in the cache and registers

- **Decode**: the CPU decodes the instruction, based on what the ISA defines that specific opcode (instruction) to be, into a hardware operation that the transistors/gates understand

- **Execute**:  the CPU executes the operation using modules such as the ALU or I/O controller

- **Store**: the CPU stores the result of the operation if required
