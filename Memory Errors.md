# Error Types 

## Soft errors/transient fault

- where memory bits dynamically change state during operation
## Hard errors/permanent faults

where the actual memory locations are defective during fabrication

# Solution
>To counter such errors

- most memory circuits are manufactured with extra rows which are used in the case of a hard error in any row, this substitution is software managed.
- Soft errors are a bit trickier to accommodate, the main approach is error correcting codes (ECC).
